# json_to_csv_files

Using this repo to work on getting the cves & cpes from NIST using api call method from https://services.nvd.nist.gov/rest/json/cves/2.0 and https://services.nvd.nist.gov/rest/json/cpes/2.0 

1. Developing .sh script to get the data and downlod to a raw json formated file
2. to write a text file with single json event from the erray in new line, so to easy to parse to csv file.
3. To create a csv file with header of the field name and then the values from each event
